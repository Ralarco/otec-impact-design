# Excelencia Digital

Basado en la imagen adjunta crea el diseño de un sitio web de una empresa dedicada a la capacitación, llamadas Otec en Chile. Usa los colores y el logo adjunto para contruir el sitio, con una orientación a la educacion y la seriedad, que refleje profesionalismo y esperiencia, y tenga un diseño de alto impacto y orientado a atraer clientes
